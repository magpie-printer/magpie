Anti-Rub Y-Carriage Mod

This mod serves to fix belt rubbing issues on some people's magpies. If you have that issue, this mod is for you.



![enter image description here](https://media.githubusercontent.com/media/magpie-printer/magpie/main/Mods/Anti-Rub%20Y-Carriages/image.jpg)
**DISCLOURE: This mod will almost certainly require supports even though the vanilla versions of Magpie parts do not require supports.


# BOM:

**You'll need to print the Toolhead belt Connector and the x-carriage front files provided in the plated parts file.**





# Assembly

Assembly should be no different from the regular y-carriages on a Magpie.
